# genealogia

Family tree app: tree, people, relationships, giỗ (lunar death anniversaries), map, printable book, GEDCOM import/export.
Client-first and offline (IndexedDB + outbox sync). Express + Postgres server, static PWA (no build step).

Status: early. The code is public so CI runs on free runners; the contribution guide, modules, languages and themes
are being built (see the project plan in issues). Contributions open later.

## Run locally
- `cd server && npm ci`
- Postgres: `bash scripts/ci-db.sh start` (throwaway container) and set `DATABASE_URL`, `SESSION_SECRET` (32+ chars).
- `node scripts/migrate.js && node scripts/seed.js` (fills an EMPTY database with an invented demo family)
- `node server.js` -> http://localhost:3090

## Tests
- `cd server && npm test` (unit + DB tests with the throwaway Postgres)
- Browser e2e: see `test/e2e/README.md`; `node scripts/affected-tests.mjs --base origin/master` lists the e2e files a change touches.

## Privacy
Living people's contacts and full dates are only sent to signed-in members (`server/core.js publicView`).
The demo data is a fictional family generated by `node scripts/make-demo-seed.mjs` (deterministic); real family data is never committed.
